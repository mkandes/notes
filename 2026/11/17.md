elasticdump (Best for exporting to raw JSON/CSV): If you want a single readable file to analyze elsewhere, the open-source command-line tool elasticdump works seamlessly with OpenSearch. You can dump all perfSONAR indices to a JSON file in one command:

```
elasticdump --input=http://localhost:9200/pscheduler_* --output=/path/to/dump.json --type=data
```
