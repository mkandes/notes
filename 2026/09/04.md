# Deploying vLLM on Expanse

### Requirements
- vLLM contains pre-compiled C++ and CUDA (12.9) binaries.
- GPU: compute capability 7.5 or higher (e.g., T4, RTX20xx, A100, L4, H100, B200, etc.)
- Not all endpoints are protected by an API key; must use gateway and/or reverse proxy to protect/drop paths
- Important: No tool servers are enabled by default. They must be explicitly opted into via configuration.
 - Most cache paths default to subdirectories under a single root. Changing VLLM_CACHE_ROOT changes the default location for all features that inherit from it.
